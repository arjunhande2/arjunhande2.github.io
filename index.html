My name is Arjun Hande, and I am currently developing my UX design skills through a course-based portfolio. I am particularly interested in creating digital interfaces that are clear, accessible, and efficient for users completing specific tasks.

As I continue to build my design experience, this portfolio emphasizes process documentation: identifying the problem, understanding the intended users, explaining design decisions, and using feedback to refine each solution.

Design Process

The following workflow outlines how I approach UX design projects. Each step represents an important part of creating a user-centered and evidence-informed interface.

01

Understand

Clarify the design problem and user needs.

02

Research

Review comparable interfaces and design patterns.

03

Prototype

Create low-fidelity layouts and interaction flows.

04

Evaluate

Evaluate the design and refine the solution.

I start by defining the purpose of the design, the target users, and the main task the user needs to complete. This helps prevent the design from becoming only visual without solving a real problem.
